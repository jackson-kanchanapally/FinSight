# Phase 8 architecture decisions (before implementation)

- Reuse Company identity and the existing company financial view. A thesis is available for any registered company, including all holdings; no portfolio aggregation is introduced.
- Pillar identities are stable. Definition revisions and expectation revisions are append-only. A manual edit records its reason and preserves the old definition; a material thesis edit starts a new unproven baseline. State evaluations are immutable records referencing the exact definition and saved analysis.
- Expectations reference InvestorCheckpoint IDs. Management targets and outcomes are read from the saved quarterly evidence registry, never duplicated into a competing checkpoint evaluator. User-authored numerical tests are explicitly user assumptions with exact metric, unit and reporting-period requirements.
- Bootstrap proposes evidence-linked definitions for review/edit/accept. It never silently activates a thesis. Origin and the act of user acceptance are distinct.
- Quarterly evaluation reuses saved AIAnalysis evidence, the existing ReviewItem validator, configured Qwen provider and deterministic fallback. Unsupported items are rejected individually. A source claim alone cannot establish delivery. BROKEN requires repeated directly failed tests across distinct periods and explicit model-supported contradiction, not a price move or one weak result.
- A current state change is recorded when evaluated; no API can backdate adoption or edits. As-of reads reconstruct stored revisions and evaluations. Historical source analysis is filtered by company, scope, period and documentary publication cutoff; future valuation snapshots and unavailable lineage are excluded. Evaluation stores the filtered evidence snapshot and exact expectation revisions used.
- Phase 6.3 remains the calculation authority. The thesis expectation gap compares its required EPS CAGR only with verified EPS CAGR over the same horizon. Quarterly YoY is labelled a horizon mismatch. Classification thresholds are exposed as an interpretation policy, not an investment score or forecast.
- The existing review gets a concise thesis-impact panel. The company view gets editable pillars, linked tests, current grouped states, evidence, gaps and an expandable immutable timeline. No new RAG, provider, peer, trading or notification system.
